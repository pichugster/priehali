# Как подключить приём заявок в Telegram

Форма на /zayavka/ отправляет данные на серверную функцию /api/lead,
которая пересылает их в Telegram-бота. Чтобы это заработало на реальном
сайте, нужно один раз настроить бота (5 минут) и прописать 2 переменные
в Vercel.

## 1. Создать бота
1. Открой Telegram, найди @BotFather
2. Отправь /newbot, дай боту имя (например, priehali_leads_bot)
3. BotFather пришлёт токен вида `123456:ABC-DEF...` — это TELEGRAM_BOT_TOKEN

## 2. Узнать chat_id, куда слать заявки
Проще всего — создать отдельную группу/канал для заявок:
1. Создай приватную Telegram-группу (например "приехали — заявки")
2. Добавь туда своего бота
3. Напиши в группу любое сообщение
4. Открой в браузере:
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
5. В ответе найди "chat":{"id": -100123456789 ...} — это TELEGRAM_CHAT_ID
   (для групп id обычно отрицательный, это нормально)

## 3. Прописать переменные в Vercel
В проекте на vercel.com → Settings → Environment Variables добавь:
- TELEGRAM_BOT_TOKEN = токен из шага 1
- TELEGRAM_CHAT_ID = id из шага 2

После этого сделай Redeploy проекта — и заявки с формы начнут падать
прямо в вашу Telegram-группу.

## Локальная проверка (необязательно)
Можно создать файл .env в корне проекта (он в .gitignore, не попадёт
в git) с теми же двумя переменными и запустить `npm run dev` —
форма заработает и локально.
