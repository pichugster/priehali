# Карта рубрик и логика профиля — портал по Нячангу

## Как работает виджет
Три таба → под каждым свои поля-выпадашки → кнопка «Показать подборку» → карточки категорий (кликаются). Категории с готовой статьёй ведут на страницу, без статьи — плашка «Скоро».

---
## ТАБ 1. ТУРИСТ
Поля: «Ты в Нячанге» (Впервые / Уже был) · «Что интересно» (Всё / Еда / Пляжи / Тусовки / Экскурсии — сделать множественным) · Город: Нячанг.
Категории:
- 🍜 Где поесть — кафе, стритфуд, рестораны
- 🏖 Пляжные клубы — где провести день у моря
- 💆 Массажи и спа — проверенные места
- 🎉 Тусовки — бары и вечеринки
- 🗺 Экскурсии — острова, водопады, туры
- 🛵 Аренда байка — где брать, цены, лайфхаки
- 🏨 Где остановиться — районы и отели
- 💸 Цены — сколько брать с собой

---
## ТАБ 2. ПЕРЕЕЗД
Поля: «Едешь» (С доходом / С накоплениями / Без дохода — одиночный) · «Состав» (Один / Пара / С детьми / С питомцем — сделать МНОЖЕСТВЕННЫМ) · Город: Нячанг.

Базовые категории (у всех):
- 🛂 Виза — как въехать и продлевать
- 🏠 Жильё надолго — районы, цены, договоры
- 🏦 Банки и деньги — карты и как платить
- 📶 Симка и интернет — связь с первого дня
- 🛵 Транспорт — байк, права, аренда
- 🩺 Медицина — клиники и страховка
- 💸 Сколько нужно денег — стартовый бюджет
- 🤝 Комьюнити — где найти своих

Добавляются по профилю:
- Без дохода → 🧑‍💻 «Научиться зарабатывать» (ссылка на pichugster), выделенная карточка
- С доходом → как получать деньги за границей, налоги, легализация
- С накоплениями → на сколько хватит, как растянуть, во что вложить
- С детьми → 🎒 Школы и садики, детская медицина, семейное жильё
- С питомцем → 🐾 Ввоз питомца, ветеринары, жильё с животными
- Пара → жильё для двоих, совместный бюджет
- Один → коливинги, как не заскучать, найти своих

---
## ТАБ 3. УДАЛЁНКА
Короткая ветка — ведёт на pichugster.com (там удалённый заработок).
Поля: «Направление» (Нейросети / Монтаж / Контент) · «Уровень» (С нуля / Уже умею).
Карточки: Заработок на ИИ, Монтаж, Контент, С чего начать → ссылки на pichugster.
