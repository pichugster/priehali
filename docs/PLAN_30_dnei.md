# План на 30 дней — портал по Нячангу

Цель месяца: собрать живой актив (наполненный портал + Telegram-канал + партнёрки), чтобы со следующего месяца пошёл первый доход.

Принципы: одна ветка глубоко → потом следующая; дом аудитории — Telegram; ритм 2–4 ч/день, выходные настоящие.

Ежедневно: блок «Стройка» (одна тема портала) + блок «Рост» (пост в Telegram, видео 2–3 раза в неделю). Контент = своя жизнь в Нячанге.

Неделя 1 — каркас + первые 3 подборки «Турист» (Где поесть → Пляжные клубы → Аренда байка). Завести Telegram-канал.
Неделя 2 — добить «Турист» (массажи, тусовки, экскурсии, жильё, цены) + подключить партнёрки (Travelpayouts: отели, туры).
Неделя 3 — ветка «Переезд» из личного опыта (виза, жильё, банки, симка, транспорт, медицина, бюджет, комьюнити).
Неделя 4 — запуск: связать «Удалёнку» с pichugster, доставить партнёрские ссылки (eSIM, страховки), лоск (птица, фото), soft-запуск, первые коллаборации.

Бизнес-модель: партнёрки (главное) → платные размещения местных → свои продукты. Первые деньги — со следующего месяца.

Формат: я даю факты/опыт из Нячанга; ассистент — структура, код, оформление, тексты в чистовик.
